# VEX Website

This site presents the team, its projects, events, sponsors, and organization-wide public information. The dashboard edits and previews that information before it is published.

## Language

**Collection**:
A named set of site records that share the same editorial structure, such as members, projects, or donors.
_Avoid_: Content type, data collection

**Draft**:
Unpublished changes prepared for one or more Collections.
_Avoid_: Form state, unsaved changes

**Publication Session**:
A reviewable set of Draft changes and assets prepared for publication as one GitHub pull request.
_Avoid_: PR session, publish job

**Asset**:
A file placed in the public site or attached to a Collection record.
_Avoid_: Upload, media file

**Archive Navigation**:
The collection browsing behavior used by members, projects, and events, including selection and direct-link state.
_Avoid_: Filtering, deep linking
